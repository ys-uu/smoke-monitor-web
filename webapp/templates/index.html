实时监控 M3 交付

M1 已完成系统骨架、MySQL 数据库与健康检查；实时推理画面将在 M3 接入。

规划能力（以最终设计文档 v0.3 为准）：

  • 视频源：样例视频下拉、本机任意绝对路径直读、浏览器上传单个视频、摄像头 0；
  • 开始前参数面板：置信度 conf、NMS IoU、推理尺寸 imgsz、投票窗口 / 阈值、事件冷却（默认 10s）、心跳 / 快照 / 循环开关；会话运行中参数锁定，停止后修改再重新开始；
  • 后端画框 + MJPEG 实时画面，展示 FPS、推理耗时、投票状态与 ALARM 红色横幅；
  • 投票确认 ALARM 后按冷却间隔自动保存标注快照与事件记录（M4）。

违规记录 M4 交付

M4 将提供：日期 / 来源 / 状态筛选、快照卡片墙与大图详情、“确认抽烟 / 误报”标记、删除记录并联动快照文件、utf-8-sig 编码 CSV 导出（Excel 直接打开中文不乱码）。
事件仅在多帧投票形成 ALARM、且距上一条同一来源记录满足冷却间隔（默认 10s，开始前可配）时写入 MySQL。

系统简介

本系统为《人工智能原理与实践》期末大作业，实现“浏览器前端展示 + Flask 后端服务与业务逻辑 + YOLO 模型进程内推理”的完整可运行应用，面向本地视频 / 摄像头完成香烟检测、多帧投票报警与事件级违规留证。 服务仅绑定 127.0.0.1，供课程设计与授权监控场景演示，检测结果仅供学习参考。

  1. 启动 Docker Desktop，等待引擎就绪；
    2.

    docker compose -f deploy/mysql/docker-compose.yml --env-file deploy/mysql/.env up -d
    3.

    4. 
              
  4. 浏览器访问 http://127.0.0.1:8010（端口以 deploy/mysql/.env 的 WEB_PORT 为准）；
    5. 
              
  5. 停止 Web：运行窗口 Ctrl+C；停止数据库用 compose stop，不要随意 down -v（会删除数据卷）。
